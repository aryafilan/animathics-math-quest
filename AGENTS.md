# Standar pengembangan Math Quest

- Pertahankan full 3D blocky avatar, arena Kartesius, kamera dan kontrol dari templates. Jangan ganti dengan 2.5D.
- Matematika menentukan tindakan fisik pemain, bukan pilihan ganda.
- Tiap game folder mandiri, minimal empat misi yang berbeda, target terbukti benar, tepat batas arena.
- Simpan soal dan target di levels.json serta HTML, sinkronkan keduanya.
- Jangan edit game referensi asli tanpa instruksi. Jangan timpa game lain saat menambah game.
- Periksa input modal, transisi ronde, game over, pointercancel, kontrol desktop dan mobile.
- Tambah katalog dan jalankan validasi sebelum commit; uji dengan browser bila memungkinkan. Catat hasil aktual, jangan klaim uji yang belum dilakukan.
